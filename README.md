**BANKING TRANSACTION AND BUSINESS ANALYSIS**


**ABOUT THE PROJECT**

This project focuses on analyzing banking transaction data using MySQL.

The analysis covers transaction performance, transaction values, success and failure rates, device usage, network performance, and fraud activity.


**PROJECT OBJECTIVES**

• Analyze banking transaction performance

• Measure success and failure rates

• Analyze transaction values by type

• Identify failure patterns

• Analyze device and network performance

• Calculate fraud rates

• Generate meaningful business insights


**DATABASE**

Database: banking_analysis

Table: banking_transactions


**KEY ANALYSIS**

• Total Transactions

• Transaction Value

• Average Transaction Amount

• Success and Failure Rate

• Failure Rate by Transaction Type

• Transaction Value by Type

• Transaction Performance by Device

• Network Slice Performance

• Average Network Latency

• Fraud Rate
